# \# AutoLoc

# 

# Plateforme de gestion de location de véhicules multi-agences.

# 

# \## Objectifs du projet

# Permettre la gestion des locations de véhicules à travers plusieurs agences :

# réservation, suivi des véhicules, facturation.

# 

# \## Acteurs identifiés

# \- \*\*Client\*\* : consulte les véhicules disponibles, effectue une réservation

# \- \*\*Agent d'agence\*\* : gère les réservations et l'état des véhicules

# \- \*\*Responsable d'agence\*\* : supervise l'activité de son agence

# \- \*\*Administrateur\*\* : gère les agences, les utilisateurs et les paramètres globaux

# 

# \## Cas d'utilisation (première liste)

# \- Réserver un véhicule

# \- Consulter la disponibilité

# \- Gérer le parc de véhicules

# \- Générer une facture

# \- Gérer les comptes utilisateurs
